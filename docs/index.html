7 inserting figures and figure captions

Code 
ggplot(my_data, aes(x = wt, y = mpg))+
  geom_point() +
  theme_minimal() +
  labs(x = "weight", y = "miles per gallon")
Tip

notice how we labeled figure above with option #| labes: fig-mpg we can then reference figure in our text as shown in Figure 1, heavier cars have lower mpg.

#Table outputs

Code 
```{r}
#| label: tbl-summary
#| tbl-cap: "average mpg by cylinder count" 

my_data %>% 
  group_by(cyl) %>% 
  summarise(avg_mpg = mean(mpg)) %>% 
  kable() #kable makes a clean markdown table
```
Tip

this time we labeled the table above with the option #| label: tbl-summary

we can reference in our text.

Please refer to Table 1 for the exact averages.
